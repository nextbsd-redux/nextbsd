# One pkg per line; lines starting with # are ignored.
# Runtime packages — installed in the chroot and shipped (read-only) in the ISO.
#
# The ACTIVE SET below is intentionally minimal: git plus a minimal XLibre
# X server with only the input/video drivers needed on real laptops and VMs.
# Shipping X in the read-only compressed base (/rofs) — instead of having the
# user `pkg install` it at runtime — keeps multi-GB installs OUT of the
# swapless RAM-backed tmpfs overlay, which OOM-kills the system otherwise
# (see #326). NOTE: do not add the full `xlibre`/`xorg` metaport here; it is
# multi-GB and blows up the cd9660 image.
#
# Everything below the active set is intentionally commented out (disabled);
# uncomment to re-enable. Also previously here, removed alongside the gershwin
# chroot build on 2026-05-12 (restore when libdispatch + GNUstep return — see
# memory freebsd_launchd_mach_gershwin_removed): libxml2, icu, libffi.

# ---- active set ----
git

# Minimal XLibre X server (NOT the full xlibre/xorg metaport) + the input and
# video drivers for laptops (synaptics/libinput-era) and VMs (vmmouse/vesa/scfb).
xlibre-minimal
xlibre-xf86-input-evdev
xlibre-xf86-input-joystick
xlibre-xf86-input-keyboard
xlibre-xf86-input-mouse
xlibre-xf86-input-synaptics
xlibre-xf86-input-vmmouse
xlibre-xf86-video-scfb
xlibre-xf86-video-vesa

# ---- firmware blobs (restore for real-hardware drivers) ----
#
# GPU firmware blobs metaport — pulls all flavored gpu-firmware-*-kmod
# subpackages.
#gpu-firmware-kmod
#
# WiFi firmware blobs. Drivers themselves are in base; firmware kmods
# are loaded when matching hardware attaches.
#wifi-firmware-iwlwifi-kmod
#wifi-firmware-rtw88-kmod
#wifi-firmware-rtw89-kmod

# ---- hypervisor guest additions (restore if running under VBox/VMware) ----
#
# vmware-checkvm and friends ship via open-vm-tools-nox11 and run on
# every boot regardless of whether the host is VMware. Drop unless
# you're actively using these hypervisors for testing.
#virtualbox-ose-additions-nox11
#open-vm-tools-nox11

# ---- network (restore for runtime networking) ----
#
# Network auto-config: dhcpcd in master mode (port supersedes base
# dhclient). Base /sbin/dhclient still works without this for the
# default DHCP path.
#dhcpcd
#
# Ports wpa_supplicant supersedes the base version (needed for any
# encrypted WiFi network).
#wpa_supplicant
